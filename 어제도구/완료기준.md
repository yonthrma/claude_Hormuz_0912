## 공통 최소선 (5)

1. **문제 10개 이상**
2. **각 문제에 정답과 해설**
3. **틀린 문제 모으기 + 틀린 것만 다시 푸는 화면**
4. **해설에 출처 표기** — 어느 파일 어느 쪽/절에서 나왔는지
5. **휴대폰에서 읽힘** — 폭 375px에서 가로 스크롤 없음

## 내가 더한 기준 (2)

6. **환각 0.** 문제마다 근거가 된 원문 한 문장을 함께 저장하고,
   그 문장이 실제 자료 안에 있는지 기계로 대조한다. **불일치 0건**이어야 한다.
   통과 못 한 문제는 화면에 내보내지 않는다.
7. **오답 기록이 재접속 후에도 남는다.** 브라우저 저장소가 아니라 서버 DB에 남긴다.

## 지어내기를 막는 줄

- **자료에 없는 내용으로 문제를 만들지 않는다.** 없으면 "자료에 없음"이라고 적는다.
- **인터넷에서 무언가를 불러오지 않는다.** 글꼴·아이콘·이미지 전부. 혼자서 열려야 한다.

## 확인하는 법

```
python build/04_check_mobile.py   # 가로 넘침 원인 0건
python build/05_verify.py         # 완료 기준 전부 통과
```

마지막은 눈으로 본다. **불을 끄고 폰으로 열어 30초 본다.**
