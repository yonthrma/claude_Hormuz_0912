# adr — 결정 기록

대상: $ARGUMENTS

## 왜 필요한가

3개월 뒤에 반드시 나오는 질문이 있다. **"이거 왜 이렇게 돼 있지?"**

코드는 *무엇을* 하는지 보여주지만 *왜 그렇게 정했는지*는 말해주지 않는다.
그 답이 없으면 다음 사람은 두 가지 중 하나를 한다 — 무서워서 못 건드리거나,
이유를 모른 채 갈아엎었다가 같은 함정을 다시 밟거나.

**결정 하나 = 파일 하나.** 짧게. 길면 안 쓰게 된다.

---

## 무엇을 기록하는가

| 기록한다 | 기록하지 않는다 |
| --- | --- |
| 되돌리기 비싼 선택 (DB, 프레임워크, 데이터 형식) | 변수명, 들여쓰기 |
| 남들이 보면 이상해 보일 선택 | 표준을 그대로 따른 선택 |
| 대안이 실제로 있었던 선택 | 선택지가 하나뿐이었던 것 |
| 나중에 누가 되돌리려 할 선택 | 쉽게 바꿀 수 있는 것 |
| **일부러 안 한 것** | |

마지막 항목이 특히 중요하다. "왜 X를 안 썼는가"는 "왜 Y를 썼는가"만큼 자주 필요하다.

판단이 애매하면 이 질문을 한다:
> **"석 달 뒤에 누가 이걸 보고 '왜?'라고 물을까?"** 그렇다면 기록한다.

---

## 절차

### 1. 결정을 한 문장으로
"우리는 ___ 하기로 한다." 현재형, 능동형.

### 2. 대안을 최소 2개 적는다
대안이 없으면 그건 결정이 아니라 기정사실이다. 기록할 필요가 없다.
"아무것도 안 한다"도 정당한 대안이다.

### 3. 이유를 적는다
아래는 이유가 **아니다**:
- "그게 표준이라서" → 어떤 표준이고, 우리 상황에 왜 맞는가
- "다들 그렇게 해서" → 우리 제약에서도 맞는가
- "명백하니까" → 명백하면 이 문서를 안 쓰고 있을 것이다
- "예전에 그렇게 했어서" → 그때 이유가 지금도 유효한가

### 4. 대가를 적는다
**모든 결정에는 대가가 있다.** 대가가 없다고 적힌 ADR 은 덜 생각한 ADR 이다.
"이걸 택해서 무엇이 어려워지는가"에 답한다.

### 5. 되돌리는 법을 적는다
이게 없으면 미완성이다. 이 결정이 틀렸다고 판명될 때
**무엇을 보고 알 수 있고, 되돌리는 데 얼마나 드는지** 적는다.

## 산출물

`docs/decisions/<NNNN>-<슬러그>.md` — NNNN 은 0001부터. 기존 폴더를 보고 다음 번호를 쓴다.

```markdown
# ADR-<NNNN>: <결정을 한 문장으로>

- 날짜: YYYY-MM-DD
- 상태: 제안 | 채택 | 폐기 | 대체됨(→ ADR-NNNN)
- 관련: <목표/명세 문서 링크>

## 맥락
<이 결정이 필요해진 상황. 무엇이 문제였는가. 2~4줄.
 이때의 제약도 여기 적는다 — 기한, 인원, 이미 정해져 있던 것.>

## 결정
우리는 ___ 하기로 한다.

## 이유
- <근거 1>
- <근거 2>

## 검토한 대안
| 대안 | 장점 | 왜 안 골랐나 |
| --- | --- | --- |
| <A> | | |
| <B> | | |
| 아무것도 안 한다 | | |

## 대가
<이 결정으로 무엇이 어려워지는가. "없음"이라고 쓰지 않는다.>

- 되돌리는 절차: <무엇부터>
```

## 상태 관리

ADR 은 **고치지 않고 쌓는다.** 이미 쓴 결정이 바뀌면:

1. 옛 ADR 의 상태를 `대체됨(→ ADR-0007)` 로 바꾼다. **내용은 그대로 둔다.**
2. 새 ADR 을 쓰고, 맥락에 "ADR-0003 을 대체한다. 그때와 달라진 것: ___" 를 적는다.

지운 기록은 기록이 아니다. 틀린 결정도 남겨야 같은 실수를 안 한다.

---

## 하지 말 것

- 결정을 내리기 **전에** ADR 쓰기 — 이건 기록이지 제안서가 아니다. 아직 고민 중이면 `/interview grill` 로 계획을 털어본 뒤에 쓴다
- 한 파일에 결정 여러 개 넣기 — 하나씩. 나중에 하나만 대체될 수 있다
- 대가 칸에 "없음" 쓰기
- 옛 ADR 을 수정하거나 삭제하기
- 모든 걸 다 기록하기 — 기록이 많아지면 아무도 안 읽는다. 위 표의 기준으로 거른다

## 완료 체크리스트

- [ ] 결정이 한 문장이다
- [ ] 대안이 2개 이상이고, 각각 "왜 안 골랐나"가 있다
- [ ] 이유가 "표준이라서" 류가 아니다
- [ ] 대가가 적혀 있고 "없음"이 아니다
- [ ] 틀렸다는 걸 알아챌 신호가 적혀 있다
- [ ] 파일이 `docs/decisions/` 에 번호 순으로 저장됐다
