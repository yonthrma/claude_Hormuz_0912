# claude_Hormuz_0912

목포해양대학교 AI 바이브코딩 **2주차 2일차 실전 과제** 준비 자료.
호르무즈 해협 자율운항선 나포 시나리오에 대한 보고서·발표자료를,
Claude Code로 **근거를 남기면서** 만들기 위한 요청 프롬프트 모음입니다.

> 시나리오(한바다오토노머스 / 한바다 3호)는 **교육용 가상 설정**입니다.
> 호르무즈 해협·이란·국제 규범·자율운항선박법은 실제이며 직접 조사 대상입니다.
> 이 구분을 흐리면 AI가 가상 사건을 실제인 것처럼 "검색해서 찾아냅니다."

## 02번 문서 구성

**본편 — 순서대로 붙여넣는 프롬프트**

| 단계 | 내용 |
| --- | --- |
| 0 | 완료기준 먼저 쓰기 |
| 1 | 자료 파악 (결론 금지, 웹 검색 금지) |
| 2 | 내부 데이터로 사실 재구성 — 모든 문장에 `[파일명/행]` |
| 3 | 외부 리서치 — **여기서만** 웹 검색. 끝나면 교차검증 |
| 4 | 보고서 (4문항 고정) |
| 5 | 발표자료 (3/4/2/1분) |
| 6 | 제출 |

**부록**

- **A. 자율성 부여** — `알아서 해줘` 대신 *판단 기준 + 확장 허가 + 보고 의무*
- **B. 스킬 활용** — [yonthrma/Claudecode_2_0905](https://github.com/yonthrma/Claudecode_2_0905) 의
  `/orient` `/adr` `/interview grill` `/handoff` 를 어디에 쓰나
- **C. TDD** — 검사기 확장 + **숫자 재현 테스트**(보고서 수치를 원본에서 다시 계산)
- **D. 프레임 주의** — "회사를 살린다"로 목표를 주면 결론이 낙관 쪽으로 기움

## 핵심 4가지

1. **가상 사건 / 실제 정세를 구분해서 알려줄 것** — 안 그러면 환각
2. **큰 파일은 "코드로 세라"** — 대화창에 CSV 붙이면 앞부분만 보고 숫자를 창작 (교안 98p)
3. **모든 주장에 `파일명 + 위치`** (교안 115p)
4. **"모르는 것"을 따로 적으라고 지시** — 안 시키면 AI는 절대 "모른다"고 안 씀

## 하지 말 것

- ❌ "호르무즈 사고 보고서 써줘" → 데이터 안 보고 그럴듯한 글만 나옴
- ❌ 로그 파일 통째로 대화창에 붙여넣기
- ❌ "이거 맞아?" → 교안 112p 금지 질문. 대신 "이 결론의 근거 파일 위치를 다시 보여줘"
- ❌ 1~5단계를 한 번에 → 중간 근거가 사라져 발표에서 방어 불가
